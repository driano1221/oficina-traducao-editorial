Measuring prediction error

A useful prediction is not necessarily an exact one. Before comparing models, decide what counts as an error.

Consider four fictional measurements. The reference rule predicts y = 2x. We define the residual as the observed value minus the prediction, so a positive residual means that the rule underestimated the observation.1

Why square the residuals?

The average residual is zero, but two predictions are wrong. Squaring prevents positive and negative errors from cancelling each other.

MSE=1n∑i=1n(yi−y^i)2

For Table 1, MSE = (0 + 1 + 1 + 0) / 4 = 0.5. The mean absolute error is also 0.5. This agreement is specific to these numbers; the two measures are not interchangeable.
